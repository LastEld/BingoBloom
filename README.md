# Bingo Bloom

Личная бинго-доска с задачами и скрытыми наградами. За собранные линии вы получаете цветы для своего гербария.

[Открыть сайт](https://bingo-bloom-sofi.vell01.chatgpt.site/) · [Как играть и сохранять прогресс](bingo-live/README.md#управление)

## Работа с проектом

Требуется Node.js 20 или новее. Выполняйте команды из корня репозитория.

| Команда | Результат |
| --- | --- |
| `npm start` | Запускает [локальную доску](http://localhost:5173/). |
| `npm test` | Проверяет игровую логику, сохранения и представления. |
| `npm run build` | Копирует сайт в папку для публикации. |

Редактируйте файлы в [public](bingo-live/public/). Папка [dist](bingo-live/dist/) содержит готовую сборку для ChatGPT Sites.
