## Иллюстрации для сравнения

В [галерее растений](specimens-v3.png) строки сверху вниз показывают ромашку, василёк, мак и клевер. В каждой строке слева направо показаны малая, средняя и крупная головки при постоянном масштабе. Примеры выбраны по ширине главной головки среди ста экземпляров каждого вида. Все 400 измерений, длины стеблей, числа ветвей и бутонов сохранены в [таблице](growth-v3-samples.csv).

В [галерее засушивания](pressing.png) те же четыре вида показаны до прессования, в середине перехода и после него. Для каждого ряда использован один и тот же экземпляр с ключом `garden-0`. Параметры проверки вынесены из изображений.

## Сборка и браузеры

Прошли все 40 тестов Node.js. У 134 ресурсов из `public` содержимое совпало с файлами публикационной копии в `dist`. Те же 134 пути вошли в список офлайн-кеша.

Локальная поставка проверена в Chrome 158 на Windows. В отдельном обычном профиле приложение установилось и открылось в собственном окне. Без сети открылись доска и книга. В приватном профиле браузер признал установку недоступной, и игра скрыла кнопку установки. Смена кеша на новую сборку сохранила содержимое прогресса. Конкурентные ходы проверены также в Edge 158. Мобильные размеры и касания проверялись эмуляцией браузера.

Запрос манифеста по публичному адресу из корневого README без авторизации вернул HTTP 401. Результаты установки и офлайн-запуска относятся к локальному HTTP-серверу с каталогом `dist`.

На шести маршрутах сверены видимые и озвучиваемые подписи. В выгруженной открытке проверены печатаемый текст, имя файла и источник растения. Версия формы, ключ генерации и параметры выборки хранятся отдельно от иллюстраций.

## Как повторить

Из корня репозитория запустите `npm test` и `npm run build`. Для ручной проверки откройте игру через `npm start`. Для проверки поставки обслуживайте каталог `bingo-live/dist` из корня HTTP-сайта. У каждого порта и профиля браузера свой прогресс. Для испытания повреждённого сохранения и импорта используйте отдельный профиль.

Для воспроизведения конфликта нужен доступный Node.js пакет `playwright` и установленный Chromium. При запущенной игре выполните `node bingo-live/scripts/check-tabs.cjs`. Адрес игры можно задать переменной `BINGO_URL`, путь к Chrome или Edge — `CHROME_PATH`. Проверка открывает отдельный контекст для каждого порядка записи и для одновременной отправки. Две вкладки начинают с одной версии. Одна отмечает первую клетку, другая вторую. Старая вкладка получает конфликт, повторяет действие и после перезагрузки видит обе отметки.
