# Bingo Bloom

Личная бинго-доска с задачами и скрытыми наградами. Первой открывается «Уютная неделя». Вкладка «Шаблоны» предлагает отдельные доски на неделю, месяц и год, а также пустую доску. Несколько циклов можно вести одновременно. Все доски доступны в меню «Мои доски».

## Запуск

В этой папке выполните `npm start` и откройте [локальную доску](http://localhost:5173/). Нужен Node.js 20 или новее. Команда `node build.js` подготавливает папку `dist` для статического хостинга. Для другого порта задайте переменную окружения `PORT`.

## Управление

- Настройте задачи и персональные награды на поле, затем нажмите **Начать бинго**. Подготовку можно продолжить после перезагрузки.
- Выберите выполненную задачу. Карточка переместится в центр. Сотрите половину поверхности мышью или пальцем. Оставшееся покрытие плавно раскрывается от границ каждого штриха. Одиночное касание стирает только участок под указателем. После раскрытия на поле видна награда. Выберите эту клетку ещё раз, чтобы прочитать её или отменить отметку.
- Каждая новая горизонталь, вертикаль или диагональ приносит свежий цветок в корзинку на шесть мест. При пересечении линий можно получить несколько цветов за одну отметку. Отменить отметку можно в карточке. Повторное закрытие той же линии сохраняет первоначальный сбор.
- **Засушить в гербарий** переносит экземпляр в книгу и окрашивает его в осеннюю палитру. Его seed определяет композицию для обоих состояний. В книге можно переключать экземпляры одного вида, добавлять личные заметки и скачивать страницы в PNG.
- **Завершить цикл** отправляет доску в историю. Корзинка и книга остаются доступны из следующей доски. Для повтора откройте завершённый цикл в истории.
- Стрелки перемещают фокус, **Enter** выбирает карточку, **Enter** или **Пробел** на её поверхности стирают по одной полосе, **Escape** закрывает. В режиме подготовки **Shift + Enter** открывает редактирование клетки.
- На баннере можно сменить длительность, размер сетки и иллюстрацию даже во время цикла. При уменьшении поля внешние клетки сохраняются до следующего расширения. В настройках можно изменить тему, звук, анимации, отображение координат и seed следующего цикла.
- **Экспорт** сохраняет PNG доски или открытку открытого экземпляра. Резервная копия JSON включает все доски, корзинку, гербарий, заметки, историю и настройки. Импорт находится в настройках.

Прогресс хранится в localStorage конкретного браузера и адреса сайта. Сохранения предыдущей версии загружаются автоматически, включая доски 4 × 4.

## Дизайн и проверка

[Редактируемый UI-кит для Figma](design/Bingo-Bloom-UI-kit.svg) содержит палитры, типографику, элементы управления и состояния клетки. Перетащите SVG на холст Figma, чтобы редактировать группы.

Проверки игрового цикла, сборки по seed, совместимости и восстановления JSON запускаются командой `npm test` из корня проекта.

## Где вносить изменения

| Задача | Файл |
| --- | --- |
| Разметка поля и состояния клетки | `public/board-view.js` |
| Корзинка, страницы гербария и история | `public/bloom-book.js` |
| Игровые правила и загрузка сохранений | `public/bloom-garden.js` |
| Навигация, диалоги и обработка действий | `public/bloom.js` |
| Стили поля и карточки | `public/bloom.css` |
| Оформление обложки, корзинки и книги | `public/bloom-herbarium.css` |

Исходники сайта находятся в `public/`. После проверки командой `npm test` выполните `npm run build` из этой папки, чтобы обновить публикационную копию в `dist/`.
