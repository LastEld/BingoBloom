# Bingo Bloom

Личная бинго-доска с задачами и скрытыми наградами. Первой открывается «Уютная неделя». Путь **Мои доски → Новая доска** ведёт к шаблонам и пустому полю. В предпросмотре можно изменить задачи, награды, порядок и оформление. Доска появляется в календаре после нажатия **Создать доску**. Несколько циклов можно вести одновременно.

## Запуск

В этой папке выполните `npm start` и откройте [локальную доску](http://localhost:5173/). Нужен Node.js 20 или новее. Команда `npm run build` подготавливает папку `dist` для статического хостинга. Для другого порта задайте переменную окружения `PORT`.

## Управление

- На первом экране **Открыть первую задачу** начинает «Уютную неделю». Чтобы сначала изменить задачи и личные награды, выберите **Настроить доску**. Подготовку можно продолжить после перезагрузки.
- Откройте выполненную задачу. Сотрите половину покрытия мышью или пальцем либо нажмите **Открыть без стирания**. Игра записывает ход при достижении порога. Можно сразу закрыть карточку. Повторный просмотр позволяет прочитать награду или снять отметку.
- Каждая новая горизонталь, вертикаль или диагональ приносит свежий цветок в корзинку на шесть мест. При пересечении линий можно получить несколько цветов за одну отметку. Отменить отметку можно в карточке. Повторное закрытие той же линии сохраняет первоначальный сбор.
- Нажмите на цветок в результате хода, чтобы найти его в корзинке. **Засушить в гербарий → Открыть лист** ведёт к этому экземпляру. В книге можно перелистывать цветы, добавлять личные заметки и скачивать открытки. После входа с клетки кнопка возврата ведёт обратно к ней.
- **Завершить цикл** помещает доску в архив и готовит следующий черновик. В **Мои доски → Завершённые** можно посмотреть итог, скачать изображение цикла или создать отдельную доску через **Действия → Повторить доску**.
- Стрелки перемещают фокус, **Enter** выбирает карточку. **Enter** или **Пробел** на её поверхности раскрывают награду, **Escape** закрывает карточку. В режиме подготовки **Shift + Enter** открывает редактирование клетки.
- В **Параметрах** поля можно менять длительность, размер и обложку даже во время цикла. При уменьшении поля внешние клетки сохраняются до следующего расширения. **Крупное поле** скрывает обложку и сворачивает бонус. Это предпочтение сохраняется на устройстве для всех досок.
- **Выбрать несколько** позволяет отметить группу за один ход. Нажмите на клетки, проведите по ним или выберите их с клавиатуры. До подтверждения выбор можно отменить. Все новые линии должны поместиться в корзинке одновременно.
- **Экспорт** сохраняет PNG доски или открытку открытого экземпляра. Резервная копия JSON включает все доски, корзинку, гербарий, заметки, историю и настройки. Импорт находится в настройках.

Прогресс хранится в localStorage конкретного браузера и адреса сайта. Сохранения предыдущей версии загружаются автоматически, включая доски 4 × 4.

В настройках блок **Без сети и установка** показывает, готова ли офлайн-копия на этом устройстве. После успешной подготовки доска, гербарий и рисунки открываются без сети. Браузер с доступной установкой показывает кнопку установки.

## Дизайн и проверка

[Редактируемый UI-кит для Figma](design/Bingo-Bloom-UI-kit.svg) содержит палитры, типографику, элементы управления и состояния клетки. Перетащите SVG на холст Figma, чтобы редактировать группы.

Цвета четырёх тем и бумаги гербария редактируются в [таблице ролей](public/styles/tokens.js). Команда `npm run build` обновляет стили тем и связанные образцы в SVG. Экспорт доски и открытки использует ту же таблицу. Геометрию фигур и расположение элементов в SVG можно редактировать отдельно.

Проверки игрового цикла, сборки по seed, совместимости и восстановления JSON запускаются командой `npm test` из корня проекта.

## Где вносить изменения

| Задача | Файл |
| --- | --- |
| Разметка поля и состояния клетки | `public/ui/board-view.js` |
| Корзинка, страницы гербария и история | `public/ui/herbarium-view.js` |
| Игровые правила и загрузка сохранений | `public/game/progress.js` |
| Навигация, диалоги и обработка действий | `public/app.js` |
| Стили поля и карточки | `public/styles/board.css` |
| Оформление обложки, корзинки и книги | `public/styles/herbarium.css` |

Исходники сайта находятся в `public/`. После проверки командой `npm test` выполните `npm run build` из этой папки, чтобы обновить публикационную копию в `dist/`.
